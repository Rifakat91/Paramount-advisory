# Paramount Advisory & Consulting – static site
Upload everything in this folder to the root of a GitHub repository, then enable Settings > Pages > Deploy from branch (main, / root).
Files: index.html, style.css, script.js, images/ (logo.png, logo-mark.png, favicon.png). All paths are relative.
For link previews, change the og:image value in index.html to the full URL of images/logo.png once the site is live.
